# 常见问题

## OTA 不触发

按顺序检查：

1. **版本号没递增**：`CMakeLists.txt` 里的 `PROJECT_VER` 与后台版本相同，设备认为已是最新；
2. **后台未发布**：记录存在但 `state` 不是发布状态，接口回退到占位版本；
3. **返回了占位版本**：接口返回 `"version": "1.0.0"`，说明后台没查到已发布固件；
4. **OTA 地址没保存成功**：重新进配网「高级选项」确认字段值仍在；
5. **下载地址不可达**：设备无法访问 `firmware.url`（内网地址、端口未放行、需要鉴权）。

## 升级完成但仍是旧功能

- OTA 上传的必须是 `xiaozhi.bin`，不是 `merged-binary.bin`；
- 手动用 esptool 调试时，要写入**当前正在运行的分区**：运行 `ota_0` 写 `0x100000`，运行 `ota_1` 写 `0x700000`。写错分区会出现「升级成功但功能没变」。

## 设备反复升级、一直停在升级界面

说明后台「登记版本」高于「实际文件内嵌版本」。设备每次升级后运行的仍是旧版本，于是又被判定有新版本。按 [OTA 接口协议](ota.md) 的「版本一致性自查」核对接口版本、文件内嵌版本和 MD5，替换后台文件即可。

## 配网页面打不开

- 确认已连上 `MJ-XXXX` 热点；
- 手动输入 `http://192.168.4.1`，不要用 HTTPS；
- 部分系统会因「无互联网」自动切回移动数据，需在系统设置中保持该 Wi-Fi 连接。

## 设备反复重启

多为显示或内存异常。可先通过串口确认是否有 `task_wdt: Task watchdog got triggered` 日志，再对照本仓库当前版本排查。

## 串口无输出

- 波特率 115200 8N1；
- 部分板子的 USB 只供电、不传输数据，这种情况只能通过配网 + OTA 升级，无法本地烧录。

## 编译时报找不到 `esp_console.h`

确认 `main/CMakeLists.txt` 中包含：

```cmake
PRIV_REQUIRES efuse console
```

本仓库已经修复。

## 分区空间不足

当前 16MB 分区表中应用分区为 6MB，编译时可能出现「分区接近占满」的警告。增加功能或资源前，应关注应用大小，必要时调整分区表或精简资源。

## 雷达/摄像头/触摸不工作

- 雷达默认启用，相关宏在 `main/application.h`（`OPEN_RADARR_MODULE`）；
- 摄像头和触摸当前固件未启用，需要自行打开初始化；
- 电池电量检测同样未启用。
