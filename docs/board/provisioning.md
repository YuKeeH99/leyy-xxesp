# 配网与 OTA 地址

这是 USB 不能传数据的板子最重要的配置入口。

## 1. 进入配网模式

任意一种方式即可：

- 设备上电后 **60 秒内连不上 Wi-Fi**，自动进入配网模式；
- 在 Wi-Fi 模式下，**长按「音量−」键（GPIO46）**，设备会清空 Wi-Fi 配置并重启进入配网；
- 设备当前是 4G 模式时，长按「音量−」会先切回 Wi-Fi 模式，再长按一次进入配网。

进入配网后，屏幕会显示热点名称和访问地址。

## 2. 连接热点

| 项目 | 值 |
| --- | --- |
| 热点名称（SSID） | `MJ-XXXX`（`XXXX` 为 MAC 地址后两字节的十六进制） |
| 热点密码 | 无（开放热点） |
| 配置页面 | `http://192.168.4.1` |

用手机或电脑连接该热点，浏览器打开 `http://192.168.4.1`。

> 部分手机连上无密码热点后会提示「无互联网，是否保持连接」，选择保持连接即可。

## 3. 页面结构

页面有两个标签页：

- **Wi-Fi**：填写要连接的 Wi-Fi 名称和密码，点「连接」；
- **高级选项**：配置自定义 OTA 地址、Wi-Fi 最大发射功率、是否记忆 BSSID。

## 4. 配置自己的后台地址

1. 打开 `http://192.168.4.1`；
2. 点击顶部 **「高级选项」** 标签；
3. 在 **「自定义 OTA 地址」** 中填入你自己的 OTA 检查接口完整 URL，例如：

   ```text
   http://your-server.com:7091/api/device/ota
   ```

4. 点 **「保存」**，页面提示保存成功后，字段值会写入设备 NVS（`wifi` 命名空间的 `ota_url`）；
5. 回到 **「Wi-Fi」** 标签，填写你的 Wi-Fi 并点「连接」；
6. **手动断电重启**设备（保存操作本身不会自动重启）。

重启后设备会：

1. 连接 Wi-Fi；
2. 用上面配置的地址请求 OTA 接口；
3. 解析接口返回的 `websocket` 配置并写入 NVS；
4. 用该 WebSocket 地址建立对话连接。

## 5. 关于 WebSocket 地址

设备**只有 OTA 地址一个手工配置入口**，WebSocket 地址不单独配置，而是由 OTA 接口返回后自动写入。因此你的后台 OTA 接口必须同时返回 `websocket` 字段，否则设备无法连上对话服务。

## 6. 地址优先级

1. 优先使用 NVS 中保存的 `wifi/ota_url`；
2. 如果为空，则回退到 `sdkconfig` 中的 `CONFIG_OTA_URL`。

本仓库 `sdkconfig` 中的默认地址：

```text
https://databerrypi.com/xiaozhi/ota/
```

## 7. 恢复默认地址

把「自定义 OTA 地址」清空并保存，设备就会回退到编译时的 `CONFIG_OTA_URL`。

## 8. 配网页面打不开

- 确认已连上 `MJ-XXXX` 热点；
- 手动输入 `http://192.168.4.1`，不要用 HTTPS；
- 部分系统会因「无互联网」自动切回移动数据，需在系统设置中保持该 Wi-Fi 连接。
